# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.x (latest) | ✅ |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public GitHub issue.

Instead, email the maintainer directly or open a [GitHub Security Advisory](https://github.com/demianabiusi/firebirdyog/security/advisories/new).

We will respond within 72 hours and coordinate a fix before public disclosure.
